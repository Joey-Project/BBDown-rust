# v0.4.0 版本说明

`v0.4.0` 发布于 2026 年 6 月 18 日，是 credential 和 danmaku maintenance release。它增加
credential profile model、login/health surfaces、generic `access_key` 获取，以及基于 archive
的 append-only 弹幕更新。

## 重点

- 增加 WEB 和 TV login flows 的 unified QR login ticket/output surfaces。
- 增加 WEB cookie、generic `access_key` 和 TV `tv_access_key` credentials 的 health
  diagnostics。
- 增加 multi-profile credential storage，同时保留 default-profile 和 legacy flat-file 行为。
- 在 CLI 和 embedding APIs 中增加 profile-aware credential selection。
- 通过 BiliPlus authorization flow 增加 generic `access_key` 获取，包括 QR/link output 和
  callback/message import。
- 加固 access-key import，避免 terminal-backed interactive paste paths 把敏感 token 回显到
  scrollback。
- 增加面向已下载 archive records 的 append-only 弹幕更新 API 和 CLI workflow。
- 增加 XML merge 行为，按 comment 去重，并重新生成 ASS 等 derived formats，同时保持 XML
  作为 canonical sidecar。

## CLI 说明

- 使用 auth/profile 命令 import、select、inspect 和 remove credential profiles。
- 对敏感 callback data 使用 access-key login/import flows 时，显式使用 `--file` 或 `--stdin`
  input sources。
- 使用 `bbdown danmaku update <input> --archive-file <path>` 刷新已有 archive records 的弹幕
  sidecars。
- 更新时可以通过 repeatable 或 comma-delimited `--danmaku-format` 值重新生成选定 derived
  formats。

## 嵌入说明

- `CredentialProfiles` 保留 default-profile 行为，同时允许 named profiles。
- Health diagnostics 返回 redacted credential probe status，不泄露原始值。
- `BiliClient::update_danmaku_for_archive` 按稳定 aid/cid identity 更新匹配 archive entries，
  并把刷新后的 sidecar paths 写回 archive。
- 使用 `DownloadMode::DanmakuOnly` 规划弹幕更新，让 update flows 不依赖 media playurl
  availability。

## 兼容性

`v0.4.0` 在增加 profile documents 的同时保留 legacy flat credential loading。Credential 和
danmaku update APIs 仍处于 pre-`1.0`；嵌入方应优先使用 constructors 和 helper methods，避免
直接构造结构体。
