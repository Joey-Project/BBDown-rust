# v0.11.0 源码准备说明

本文记录 2026-10-20 的 `0.11.0` 源码准备状态，不构成发布公告。截至该日期，最新已发布版本为
`0.10.0`。当前发布状态请查看 [GitHub Releases 官方页面](https://github.com/Joey-Project/BBDown-rust/releases)。

## 重点

- 在国内 PGC season metadata 和 CLI 输出中保留主分组与补充分组。原有扁平 episode 列表、选择索引和
  仅针对主分组的 `Latest` 行为继续保留。构造 `SeasonMetadata` 字面量的 Rust 调用方需要提供新增的
  `episode_groups` 字段；不含该字段的旧 JSON 会反序列化为空列表。
- 新增普通视频关键词搜索，支持选择页码和排序。只有调用方明确选择结果后，才会进入现有 UGC/PGC 流程；
  搜索结果在此之前仅是 metadata。搜索不是自动下载列表；识别选中结果的 PGC episode 需要受支持的官方
  episode redirect，并由 season metadata 确认身份。
- 新增匿名番剧与国创时间表 metadata，包含单独的 latest 区块、有序日期分组、episode 身份和发布/延迟字段。
  此功能不添加通用输入或下载行为。
- 新增匿名 PGC 电影与电视剧分类索引页面，以及相应筛选和排序选项。列表仅提供 metadata，不会自动加载
  season、添加通用输入或开始规划和下载。
- 通过 `bbdown popular` 和 `BiliClient::popular_videos` 新增一页匿名热门视频 metadata。
- 通过 `bbdown ranking` 和 `BiliClient::ranking_videos` 新增匿名全站排行榜 metadata。先从
  `/x/web-interface/nav` 获取公开 WBI keys，再发送带签名的排行榜请求，参数为 `rid=0`、`type=all` 和
  `web_location=333.934`。缺失或空白 BVID 仍保持缺失；客户端不增加原始行数上限。

## API 边界与限额

- 搜索每次获取一页，最多接收 20 条原始记录，每个 response 上限为 1 MiB，导航和搜索最多使用两次匿名
  API 请求。关键词长度须为 1–200 个 UTF-8 字节且不能包含控制字符。支持的排序为 `totalrank`、`click`、
  `pubdate`、`dm`、`stow` 和 `scores`。搜索 metadata 使用 `api_base`；选中结果的 PGC metadata 使用
  `pgc_base`。
- 时间表通过 `pgc_base` 发起一次匿名请求，JSON response 上限为 1 MiB，解码数据最多包含 32 个日期分组和
  4096 条聚合原始记录。
- 电影和电视剧索引请求使用 `pgc_base`，每次只获取一页，每个 response 上限为 1 MiB。页码必须为正数，
  page size 为 1–20。筛选值不能为空、不能包含控制字符，且不得超过 256 个 UTF-8 字节。筛选选项按来源
  metadata 返回，不会推断分类标识。
- 热门视频请求使用 `api_base`，每次获取一页，response 上限为 1 MiB，page size 为 1–20。是否有后续页
  由上游 `no_more` 字段决定；该接口不提供总数。
- 排行榜的导航和排行榜请求都使用 `api_base`。默认每个 response 上限为 1 MiB。
  `RankingVideoOptions.max_response_bytes` 和 `--max-response-bytes` 使用同一个正数上限，分别应用于两个
  response；零会在 HTTP 请求前被拒绝。排行榜按来源顺序返回所有有效记录，不添加原始行数上限。
- 搜索、时间表、PGC 索引、热门视频和排行榜 metadata 路由具有各自独立的 endpoint 能力。
  `api_base` 与 `pgc_base` 是不同配置，`PgcWebPlayurlRoute` 只控制 PGC Web playurl。配置 gateway 或
  playurl route 并不保证它支持其他 metadata endpoint，也不保证所有地区均可访问。
- 这些 API 用于枚举 metadata，不承诺播放或媒体可用。热门和排行榜内容会随请求变化，多次请求之间不共享
  稳定快照。
- `Input::VideoSearch` 和 `VideoCollectionKind::Search` 是新增的公开 enum variant，下游 exhaustive match
  需要处理它们。构造 `SeasonMetadata` 字面量的现有调用方也需要按上文增加 `episode_groups`。
