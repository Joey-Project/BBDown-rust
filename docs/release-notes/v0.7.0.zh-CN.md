# v0.7.0 版本说明

`v0.7.0` 是 Rust 重写版本的网络与下载器版本线。它为已解析的媒体下载增加显式、可选的 CDN
控制，并提供独立的 PGC Web playurl 路由 API。内置目录用于查看和选择候选项，不会创建自动
路由策略。

## 重点

- 增加可重复使用的 `--cdn-host` 选择，以及 `MediaHostOptions::with_cdn_hosts` 有序 host pool。
  现有 `--upos-host` 仍是单独的手动 host override。
- 增加可选的 `--cdn-probe` 和 `probe_media_cdns(...)` Range 测量。每次最多探测 8 个候选，每个
  候选最多读取 64 KiB；媒体大小未知时，用于发现大小的有界请求也计入此预算。只有明确运行
  探测时才会发起真实请求；探测排名不能保证签名 URL 能在另一个 host 上使用。
- 增加可选并行 Range 传输。CLI 的 `--cdn-parallel` 默认为 1（关闭），可设置为 2 到 8。并行
  传输要求 Range 响应兼容且总长度一致；多 host 分片还要求候选 URL 的 scheme、path、query
  和初始字节样本相同。分片失败时可重试其他候选；可恢复的失败会回到常规下载路径。大小和
  前缀相同无法证明不同 host 后续字节一致，并行传输也不保证提速。
- 内置区域 CDN host 快照和历史公共 resolver 目录。可通过 `bbdown cdn list`、
  `bbdown cdn probe` 和 `bbdown resolver list` 查看。用户必须显式选择 preset 或 resolver；
  目录条目不保证可用。只有运行相应命令或显式传入选项时，才会向选定 host 发起运行时探测
  或下载请求。
- 增加 `PgcWebPlayurlRoute` 和 `ClientConfig::with_pgc_web_playurl_route(...)`，用于 PGC Web
  playurl 规划。默认 `OfficialThenProxy` 保留已配置的区域错误回退；`OfficialOnly` 跳过代理
  回退，`ProxyOnly(proxy)` 只请求选定代理。该设置不改变 PGC metadata 或 TV/APP playurl 请求。
  选定代理可能收到分集和区域请求数据，并可能收到已配置的通用 access key；Web cookie 不会发给
  该代理。

## 验证与限制

本地 HTTP mock 覆盖目录选择、CDN 探测和传输，以及受限区域 PGC API-path 路由，不需要公共网络
请求或凭据。可选 live 验证与 mock 分开：CDN benchmark 对 public 视频发起请求且不需要凭据；
受限区域 PGC live 验证会使用用户本地配置的 Web cookie 和通用 access key 访问显式选定的端点。
不要把这些凭据放入报告或 artifact。

受控 CDN 对比覆盖两种媒体大小、两个较短的上午时段，共有 18 次成功下载。结果随 host、大小和
时间变化，无法证明稳定提速、全天或多地点性能分布，也不能据此确定默认路由策略。输出 hash
只比较已完成的样本，不能证明所有 CDN 边缘节点的内容恒等。分片字节报告统计已发布文件的
字节，不是总 wire traffic。候选排除原因、跨候选重试诊断和 HTTP response-body 字节统计仍属
后续工作；自动路由、持久路由健康状态和自适应策略也继续延期。即使统计 response-body 字节，
也不等同于全部 wire traffic。

## Embedding 与兼容性

`bbdown-core` 仍处于 pre-1.0。本版本增加 public configuration 和 API surface；不同版本之间不
保证下游 source compatibility。配置优先使用 `Default`、`new` 和 `with_*` 构造器，不要依赖
public struct literals；输出结构体应作为返回值或通过 serde 消费。`PgcWebPlayurlRoute` 等 public
enum 为 non-exhaustive，应保留 wildcard match arm。该 route API 只影响 PGC Web playurl planning，
不会在后台竞速请求；应用若需比较官方与代理结果，应自行创建并协调请求。

命令和 API 详情见[用户指南](../user-guide.zh-CN.md)、[嵌入指南](../embedding.zh-CN.md)和
[架构指南](../architecture/rust-rewrite.zh-CN.md)。
