# v0.11.1 发布说明

当前发布状态和下载资产请查看 [GitHub Releases 官方页面](https://github.com/Joey-Project/BBDown-rust/releases)。

## 重点

- 使用已发布的 `danmaku-renderer` `0.1.0` crate 替换内部 ASS renderer。新增公开的 `decode_danmaku_xml` 和
  `render_danmaku_ass` API，供嵌入应用在不进行网络或文件系统 I/O 的情况下解码并渲染弹幕。这两个 API 均为
  已发布 `0.11.0` 之后新增。解码支持明文、gzip、zlib 和 raw DEFLATE；解码后的 XML 限制为 16 MiB。渲染最多接受
  50,000 个直接 comment，并检查保守估计的 48 MiB ASS 输出上限。依赖确切 ASS 格式的消费者应检查生成的输出。
- 增加按 capability 声明的 metadata service 路由，用于国内 PGC 分集/season、media-review、时间表及电影/电视剧索引
  metadata。`index` capability 独立声明；配置 metadata service 不代表支持搜索、PUGV 或国际站 metadata。
- 增加 UGC 合集和系列解析的有界选项。原有完整结果 API 保留。默认限制为每个 response 1 MiB、10 个请求、100 个原始
  archive、100 个展开页面及 4 MiB 返回字符串；硬上限分别为 16 MiB、512 个请求、4096 个 archive、4096 个页面及
  64 MiB。各阶段会在解析响应或扩展结果前检查相应限额。
- 增加匿名分区视频首批 metadata 和 `category list`。该命令不会获取分区目录或后续批次，也不会选择条目、补充详情、规划
  或下载媒体。独立的 `category catalog` 离线公开前端内置的频道菜单回退快照；它不是当前生效菜单，也不是完整分类体系。
- 将发布工作流中的 crate 发布迁移至 crates.io OIDC trusted publishing。目标 crate 版本不存在时才执行认证；版本已匹配时
  跳过认证。
