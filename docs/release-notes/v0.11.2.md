## Download Output

- Fix FFmpeg muxing failures by explicitly selecting the container for the staging file. BBDown
  replaces the final file only after muxing succeeds.
- Select Matroska with `bbdown download --mux-format mkv` or `DownloadOptions::with_mux_format`.
  MP4 remains the default when muxing is enabled.
