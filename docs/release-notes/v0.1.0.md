# v0.1.0 Release Notes

Published on June 9, 2026, `v0.1.0` is the first protected release of the Rust rewrite. It
establishes the `bbdown-core` crate, the `bbdown` CLI, the CI/release pipeline, and the first
usable downloader surface.

## Highlights

- Added the Rust workspace foundation, formatter/linter/test CI, crate packaging metadata, and the
  `bbdown-core` package name.
- Added input parsing, stream planning, quality listing/selection, download execution, subtitles,
  danmaku XML sidecars, muxing, retry/resume behavior, and JSON CLI output.
- Added WEB and TV QR login groundwork plus credential import/export surfaces.
- Added restricted-area PGC fallback through configured proxy chains, including intl/Bstar
  response compatibility and diagnostics.
- Added manifest-driven live e2e coverage for public and restricted-area samples.
- Added download archive duplicate handling so callers can detect existing outputs and choose
  replace, keep-both, or cancel behavior.
- Added English and Simplified Chinese human-facing docs for the README, user guide, embedding
  guide, architecture guide, and release runbook.
- Added the protected RC-first release flow and CLI `bbdown --version`.

## CLI Notes

- `bbdown info`, `bbdown plan`, and `bbdown download` are the primary commands in this line.
- Restricted-area downloads require configured credentials and proxy candidates.
- Release archives contain the CLI, license, README files, user guide, embedding guide, release
  runbook, and architecture docs.

## Embedding Notes

- Use `bbdown-core` as the package dependency and import it as `bbdown_core`.
- Prefer the builder and client APIs over direct construction of output models; the crate is still
  pre-`1.0`.
- Archive duplicate handling is available for API callers through typed preflight and decision
  surfaces.

## Compatibility

This is the initial public compatibility point for the Rust rewrite. Later pre-`1.0` releases may
add fields and adjust typed output shapes as the BBDown parity surface grows.
