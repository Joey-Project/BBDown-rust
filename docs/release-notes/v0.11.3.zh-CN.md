# v0.11.3 发布说明

当前发布状态和下载资产请查看 [GitHub Releases 官方页面](https://github.com/Joey-Project/BBDown-rust/releases)。

## 二维码登录

- `auth login-web` 和 `auth login-tv` 会在空间足够的交互式终端中显示二维码，设置 `NO_COLOR` 后也会显示。终端过小时仍会显示扫码链接和备用提示。
- 使用 `--qr-output FILE` 可保存为独立 SVG，且不会覆盖已有文件。重定向输出或使用 `--json` 时也可保存。

## 文档和依赖

- 新增中英文 CLI 快速开始指南。
- 将 `quinn-proto` 更新至 0.11.19、`rustls` 更新至 0.23.46，并更新相应锁定的传递依赖。

用法和发布流程见[用户指南](../user-guide.zh-CN.md)、[嵌入指南](../embedding.zh-CN.md)及[发布手册](../release.zh-CN.md)。
