# v0.11.2 发布说明

当前发布状态和下载资产请查看 [GitHub Releases 官方页面](https://github.com/Joey-Project/BBDown-rust/releases)。

## 下载输出

- 修复 FFmpeg 无法识别暂存文件容器的问题。BBDown 显式指定输出容器，并在封装成功后替换成品文件。
- 通过 `bbdown download --mux-format mkv` 或 `DownloadOptions::with_mux_format` 选择 Matroska。启用封装时默认输出 MP4。
