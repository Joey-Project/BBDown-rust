# v0.9.0 版本说明

`0.9.0` 源码版本增加结构化 CDN 传输诊断，并通过 WBI 签名个人空间动态流请求。以下内容
保留现有兼容性策略和分页行为；这些新增功能不代表自动 CDN 路由或播放验收。

## 重点

- 通过 `DownloadProgressSink`、`probe_media_cdns_with_progress` 和 CLI `--progress-json` 暴露
  类型化的 `DownloadProgressEvent::TransferBytesReceived` 与
  `DownloadProgressEvent::TransferDiagnostic`。诊断描述候选选中或排除、重试和整文件回退原因、
  请求阶段和结果、解析后的主机名，以及应用已消费的响应正文字节数。
- 使用现有 WBI 密钥查询和签名器签名个人空间动态流请求。初始请求和后续分页都会对完整查询参数
  签名，包括 `offset`；现有 `Following` 动态流请求行为保持不变。

## 字节语义

`bytes_delta` 是单次事件从一个响应正文中消费的字节数；`bytes_received` 是该请求的累计水位值。
计算已消费正文总量时应累加 delta，不应再次累加累计字段。这些计数与写入或发布到文件的字节不同。
它们受透明响应解码影响，可能包含部分失败、重试或取消请求已消费的正文，不代表压缩后的实体字节或
全部线路传输量。正文尚未消费就被拒绝的响应计为零。

## 限制

- CDN 候选选中仅表示样本、大小和路径/查询参数预检找到了兼容组，不证明完整表示身份。诊断不会新增
  表示验证器，也不会改变候选兼容规则。
- 生产分片仍固定为 1 MiB。本源码版本不增加自适应分片大小、自动路由、持久路由健康状态、从中断处
  续传、并发冗余请求（同时发起多个请求并采用先返回结果的策略）或吞吐提升声明。
- 动态流条目是元数据记录；条目数量不能证明其中多少条可播放或下载。
