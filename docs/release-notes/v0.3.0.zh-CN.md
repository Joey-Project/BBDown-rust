# v0.3.0 版本说明

`v0.3.0` 发布于 2026 年 6 月 15 日，是 feed/list parsing 版本。它把多个 Bilibili 页面族
放到共享 collection resolver 上，让 `info`、`plan`、`playback` 和 `download` 可以复用相同
selection 与普通视频规划路径。

## 重点

- 增加 list-like Bilibili page families 的共享 feed/list resolver abstraction。
- 增加已登录历史记录解析，当前覆盖 normal-video `archive` history records。
- 增加已登录关注 feed 解析和空间动态视频 feed 解析。
- 增加通过 WBI recommendation endpoint 的首页推荐解析。
- 增加通过 WEB toview endpoint 的已登录稍后再看解析。
- 新输入复用既有 collection selection semantics：all/default、latest、page 和 index/range
  selection。
- 选中的 feed/list items 会映射回普通视频规划，因此 stream、subtitle、danmaku、cover、
  playback 和 download 行为保持一致。

## CLI 说明

- 新输入 shorthand 包括 `history`、`following`、`recommendations`、`recommend`、`watchlater`、
  `watch-later`、`watch_later`、`later` 和 `toview`。
- 支持 Bilibili 历史记录、动态/关注页面、首页推荐和稍后再看/list URL。
- 历史记录、关注/动态和稍后再看需要 WEB cookie。推荐页解析使用 public WBI endpoint 行为。
- 非视频 feed cards 会被跳过，直到对应 item family 有专门的 planning support。

## 嵌入说明

- 共享 feed/list resolver 继续把公开输出形状保持为 `ResolvedContent::Collection`。
- Feed/list item deduplication 和一基 renumbering 会在选中 item 映射回普通视频规划前完成。
- 显式 index/range selection 可以在覆盖最大请求 index 后停止分页。

## 兼容性

`v0.3.0` 增加了新的 input families 和 collection kinds。嵌入方应尽量使用 non-exhaustive
matching patterns 或 serde-compatible consumers。
