# v0.1.0 版本说明

`v0.1.0` 发布于 2026 年 6 月 9 日，是 Rust 重写的第一个受保护正式版本。它建立了
`bbdown-core` crate、`bbdown` CLI、CI/release pipeline，以及第一版可用 downloader surface。

## 重点

- 增加 Rust workspace 基础、formatter/linter/test CI、crate packaging metadata，以及
  `bbdown-core` package name。
- 增加 input parsing、stream planning、quality listing/selection、download execution、字幕、
  弹幕 XML sidecar、muxing、retry/resume 行为和 JSON CLI 输出。
- 增加 WEB 与 TV QR login 基础，以及 credential import/export surfaces。
- 增加通过配置 proxy chain 的 restricted-area PGC fallback，包括 intl/Bstar response
  compatibility 和 diagnostics。
- 增加 manifest-driven live e2e，覆盖 public 和 restricted-area 样例。
- 增加 download archive duplicate handling，让调用方可以检测已有输出并选择 replace、
  keep-both 或 cancel。
- 增加 README、用户指南、嵌入指南、架构指南和 release runbook 的英文/简体中文文档。
- 增加受保护的 RC-first release flow 和 CLI `bbdown --version`。

## CLI 说明

- `bbdown info`、`bbdown plan` 和 `bbdown download` 是这一版本线的主要命令。
- Restricted-area 下载需要配置 credentials 和 proxy candidates。
- Release archives 包含 CLI、license、README、用户指南、嵌入指南、release runbook 和架构
  文档。

## 嵌入说明

- 依赖 package 使用 `bbdown-core`，Rust import 路径是 `bbdown_core`。
- 优先使用 builder 和 client APIs，不要直接构造输出模型；crate 仍然是 pre-`1.0`。
- API 调用方可以通过 typed preflight 和 decision surfaces 使用 archive duplicate handling。

## 兼容性

这是 Rust 重写的第一个公开兼容点。后续 pre-`1.0` release 可能随着 BBDown parity surface
增长而增加字段或调整 typed output shapes。

## 发布验证

- Final tag：`v0.1.0`。
- GitHub Release：<https://github.com/Joey-Project/BBDown-rust/releases/tag/v0.1.0>。
- crates.io package：<https://crates.io/crates/bbdown-core/0.1.0>。
- 该版本从 `v0.1.0-rc.1` 通过受保护的 production 和 crates.io environments promote。
- Release artifacts 覆盖 Linux x86_64、macOS aarch64、macOS x86_64 和 Windows x86_64
  archives，并带 SHA-256 sidecars。
