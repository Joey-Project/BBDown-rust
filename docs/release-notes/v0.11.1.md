# v0.11.1 Release Notes

See the [official GitHub Releases](https://github.com/Joey-Project/BBDown-rust/releases) page for
the current publication status and downloadable assets.

## Highlights

- Replace the internal ASS renderer with the published `danmaku-renderer` `0.1.0` crate. Add public
  `decode_danmaku_xml` and `render_danmaku_ass` APIs so embedding applications can decode and render
  danmaku without network or filesystem I/O. Both APIs are new since the published `0.11.0` release.
  Decoding supports plaintext, gzip, zlib, and raw DEFLATE input; decoded XML is limited to 16 MiB.
  Rendering accepts at most 50,000 direct comments and checks a conservative 48 MiB ASS output
  estimate. Consumers that depend on exact ASS formatting should check generated output.
- Add capability-declared metadata-service routes for domestic PGC episode/season metadata,
  media-review metadata, timetable metadata, and movie/TV index metadata. The `index` capability is
  separate; configuring a metadata service does not promise support for search, PUGV, or international
  metadata.
- Add bounded UGC collection and series resolution options. The existing full-result APIs remain
  available. Defaults are 1 MiB per response, 10 requests, 100 raw archives, 100 expanded pages, and
  4 MiB of returned string data; hard ceilings are 16 MiB, 512 requests, 4096 archives, 4096 pages,
  and 64 MiB. Limits are checked before response parsing or result expansion at the relevant stage.
- Add anonymous first-batch category-video metadata and `category list`. The command fetches neither
  the category catalog nor later batches, and does not select entries, hydrate details, plan, or
  download media. `category catalog` separately exposes the frontend's bundled channel-menu fallback
  snapshot offline; it is not the effective menu or a complete taxonomy.
- Migrate crate publication in the release workflow to crates.io OIDC trusted publishing. The
  workflow authenticates only when the target crate version is absent and skips authentication when
  a matching version already exists.

## Compatibility
