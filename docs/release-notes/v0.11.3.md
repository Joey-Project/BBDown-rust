# v0.11.3 Release Notes

See the [official GitHub Releases](https://github.com/Joey-Project/BBDown-rust/releases) page for
the current publication status and downloadable assets.

## QR Login

- `auth login-web` and `auth login-tv` display a QR code in interactive terminals when it fits,
  including when `NO_COLOR` is set. Small terminals keep the scan URL and show a fallback hint.
- Use `--qr-output FILE` to save a standalone SVG without overwriting an existing file. This also
  works with redirected output and `--json`.

## Documentation and Dependencies

- Add bilingual CLI Quick Start guides.
- Update `quinn-proto` to 0.11.19 and `rustls` to 0.23.46, including their locked transitive
  dependency updates.

See the [user guide](../user-guide.md), [embedding guide](../embedding.md), and
[release runbook](../release.md) for usage and publication details.
