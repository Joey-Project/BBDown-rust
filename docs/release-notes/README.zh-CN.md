# 版本说明

这个目录保存 Rust 重写版本的人类可读 release notes。GitHub Releases 仍然是下载 assets 和
自动生成 changelog 的来源；这里的文档总结每条已发布版本线对用户和嵌入方的影响。

## 版本

- [v0.6.0](v0.6.0.zh-CN.md)：credential lifecycle integration，包括 profile status、
  provider-aware access-key refresh、credential preflight 和更安全的 multi-account updates。
- [v0.5.0](v0.5.0.zh-CN.md)：downloader 和 embedding polish，包括 progress callback、
  cancellation、章节 metadata、音频语言选择和 AI 字幕筛选。
- [v0.4.0](v0.4.0.zh-CN.md)：credential lifecycle 基础、credential profiles、
  access-key 登录和 append-only 弹幕更新工作流。
- [v0.3.0](v0.3.0.zh-CN.md)：历史记录、关注/动态 feed、首页推荐和稍后再看的 feed/list
  解析。
- [v0.2.0](v0.2.0.zh-CN.md)：BBDown parity 扩展，包括批量输入、sidecars、单独下载模式、
  host controls、playback request planning 和 APP/TV playurl modes。
- [v0.1.0](v0.1.0.zh-CN.md)：首个受保护发布版本，包含 crate/CLI 基础、规划、下载、
  restricted-area proxy fallback、live e2e、archive duplicate handling、双语文档和 release
  automation。
