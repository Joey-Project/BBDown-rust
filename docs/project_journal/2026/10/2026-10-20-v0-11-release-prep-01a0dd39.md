# v0.11.0 Release Preparation

## Summary

- Prepare bilingual `0.11.0` source notes and release-note index entries for the six merged feature
  slices #105–#110. The latest published release remains `0.10.0` as of 2026-10-20.
- Record source-preparation state separately from publication. This work does not create a release
  tag or RC and does not publish a GitHub Release or crate.
- Keep historical feature validation attached to its original feature candidate; the current
  release-preparation head still needs its own CI result.

## Included Feature Scope

- PR [#105](https://github.com/Joey-Project/BBDown-rust/pull/105) preserves domestic PGC main and
  supplementary episode groups while retaining the flat episode list, global selection indexes,
  exact EP selection, and main-episode-only `Latest` behavior. `SeasonMetadata` gains
  `episode_groups`; older JSON defaults it to an empty list, while Rust struct literals must provide
  the added field.
- PR [#106](https://github.com/Joey-Project/BBDown-rust/pull/106) adds one-page ordinary-video
  keyword search and explicit page selection into the existing UGC/PGC flow. Only explicitly
  selected rows are hydrated. `Input::VideoSearch` and `VideoCollectionKind::Search` are public enum
  variants, so downstream exhaustive matches must handle them. Selected-row PGC recognition requires
  the supported official episode redirect and season identity confirmation.
- PR [#107](https://github.com/Joey-Project/BBDown-rust/pull/107) adds anonymous anime and Chinese
  animation timetable metadata, preserving the latest block, day grouping, episode identity, and
  publication/delay state. It adds no generic input or download path.
- PR [#108](https://github.com/Joey-Project/BBDown-rust/pull/108) adds anonymous PGC movie and TV
  category index pages and filter metadata, without automatic hydration, selection inputs, planning,
  or downloads.
- PR [#109](https://github.com/Joey-Project/BBDown-rust/pull/109) adds one-page anonymous popular
  video metadata. The endpoint returns `no_more` rather than a total and does not automatically
  paginate.
- PR [#110](https://github.com/Joey-Project/BBDown-rust/pull/110) adds anonymous global ranking
  metadata: public WBI navigation keys and a signed request with `rid=0`, `type=all`, and
  `web_location=333.934`. Missing or blank BVIDs remain absent; there is no arbitrary row cap. The
  default 1 MiB response cap applies separately to navigation and ranking responses; callers can
  set the same positive cap through `RankingVideoOptions` or `--max-response-bytes`, and zero is
  rejected before HTTP.

## Endpoint And Evidence Boundaries

- Search and ranking use `api_base`; timetable, movie/TV category metadata, and selected PGC search
  hydration use `pgc_base`. `PgcWebPlayurlRoute` continues to control PGC Web playurl only. These
  settings do not imply universal gateway support or regional access.
- Metadata enumeration does not establish playback or media availability. Automatic CDN routing
  and adaptive routing remain unimplemented. The pending dynamic V2 acceptance work remains
  unresolved.
- The feature journals contain their original tests, CI results, and bounded metadata observations.
  Those results were collected on earlier candidate heads and are not current-head release-prep
  validation. No new live request or media probe was run for this release preparation.
