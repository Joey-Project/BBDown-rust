# v0.11.3 Release Preparation

## Summary

- Prepare source metadata and bilingual release notes for `0.11.3`; publication and full release validation remain separate gates.
- Carry the terminal QR login, bilingual CLI Quick Start, and dependency updates from PRs #133, #132, #134, and #135.

## Included Changes

- Bump `bbdown-core` and `bbdown-cli` to `0.11.3`, including the CLI's local core version constraint and lockfile package entries.
- Document terminal QR rendering for Web and TV login, `NO_COLOR`, small-terminal fallback, and opt-in SVG output with `--qr-output`.
- Keep the Quick Start's v0.11.2 scan-URL behavior as compatibility history and identify automatic QR rendering as available starting with v0.11.3.
- Record `quinn-proto` 0.11.19 and `rustls` 0.23.46 with their locked transitive dependency updates.

## Local Validation

- Source checks: `git diff --check`, manifest and lockfile version consistency, and project journal validation.
- Formatting, strict Clippy, and the declared Rust 1.95 workspace check passed.
- The workspace suite passed 1,073 tests with four ignored. The 215 standalone CLI integration
  tests also passed and overlap the workspace suite.
- Cargo's publish dry run verified the 45-file `bbdown-core v0.11.3` package. Cargo reported the
  pre-existing `spin 0.9.8` yank warning.
