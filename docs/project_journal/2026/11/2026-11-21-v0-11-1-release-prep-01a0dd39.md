# v0.11.1 Release Preparation

## Summary

- Prepare the `0.11.1` source metadata, bilingual release notes, and narrowly scoped availability
  updates for the changes merged since `0.11.0`.
- This journal records source preparation and local validation only. Release/tag/RC creation,
  publication, and live crates.io OIDC exchange remain separate gates.

## Included Changes

- Replace the internal ASS implementation with `danmaku-renderer` `0.1.0` and expose bounded public
  XML decoder and ASS renderer APIs. The APIs are new since published `0.11.0`; generated ASS output
  may differ for consumers that depend on exact formatting.
- Add capability-declared domestic PGC episode/season, media-review, timetable, and movie/TV index
  metadata routes, with independent endpoint capabilities.
- Add bounded UGC collection and series resolution options while preserving existing full-result APIs.
- Add category first-batch video metadata, `category list`, and an offline bundled channel-menu
  fallback snapshot API/CLI.
- Migrate crate release publication to crates.io OIDC trusted publishing. The local gate below does
  not exercise identity exchange or publication.
- Source review found additive public APIs and no removed public items or changed existing public
  signatures in this range. No compatibility break was identified that changes the requested patch
  release decision.
