# Release 0.1.0

## Summary

- `v0.1.0` has been published from release candidate `v0.1.0-rc.1`.
- The GitHub Release and `bbdown-core` crates.io package both target source commit
  `31a398e32517a72a64d864d43fd48e089a7bf99c`.
- The first release completed through the protected RC-first flow: create an RC tag after full
  verification, promote that RC through the `production-release` environment, then publish
  `bbdown-core` through the `crates-io` environment.

## Current State

- GitHub Actions promote run `27209350734` completed successfully.
- Final tag: `v0.1.0`.
- Final release URL: `https://github.com/Joey-Project/BBDown-rust/releases/tag/v0.1.0`.
- crates.io package: `https://crates.io/crates/bbdown-core/0.1.0`.
- GitHub Release assets include Linux x86_64, macOS aarch64, macOS x86_64, and Windows x86_64
  archives plus SHA-256 sidecars.
- The macOS aarch64 release archive contains the CLI, license, English and Simplified Chinese
  READMEs, user guide, embedding guide, release runbook, and architecture docs.
