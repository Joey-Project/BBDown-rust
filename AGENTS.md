# Repository Instructions

- Use the local `gh` CLI for GitHub write operations so writes use the `JoeyTeng-Codex`
  GitHub account configured on this machine.
- Do not use the Codex GitHub connector for write operations such as creating pull
  requests, posting comments, submitting reviews, editing labels, or updating refs.
  Connector reads are acceptable when they are useful.
- Create pull requests with `gh pr create`; use `JoeyTeng` only for human Code Owner
  approvals.
